# generated-templates

A collection of reusable project templates. Each folder is self-contained: copy
it into a new repo and start from there.

| Template | What it's for |
|---|---|
| [`agentic-novel/`](agentic-novel/) | Novel-writing workspace for an AI assistant: story bible, scene cards, continuity/reveal/setup ledgers, and CLAUDE.md rules that keep prose show-don't-tell |
